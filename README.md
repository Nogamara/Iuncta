# Iuncta

This is a personal fork of [Inomena](https://github.com/p3lim-wow/Inomena), started in February
2026 in preparation for Midnight.

It does not really have a lot of changes, mostly stripping it down to just the unit frames and
a couple of QoL changes.

It is _highly_ opinionated and there are no configurable options.
You really shouldn't be using this if you are not me. (Yep, still true for the fork.)

## Contents

Most of this are just the unit frames, absolutely positioned.

There are some small fixes and changes I kept from Inomena, but most of it was disabled:

  * F12 to reload
  * some CVars
  * standalone coordinates on worldmap
  * add faction and race info to character frame
  * right-click to hide slots in the dressing room
  * hide BagsBar and WeeklyRewardsFrame
  * remember last recipient when sending mail
  * click through toasts
